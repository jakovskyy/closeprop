# CloseProp website and dashboard demo

The CloseProp marketing site and the dashboard demo as they stand on 18 November 2026.

## Open it

Open `index.html` in a browser. Every page of the site is in that one file and switches without reloading. The dashboard demo is `dashboard.html`, also linked as "Dashboard demo" in the site's footer. The moon button in the header switches the site to dark mode.

## Files

- `index.html`: the website
- `dashboard.html`: the dashboard demo, with sample deals and a role switch for agent, attorney and loan officer
- `assets/`: logos, photos, drawings, product captures and short videos. A file ending in `-dark` is the dark mode version of the file with the same name.

The site loads IBM Plex Sans from Google Fonts, so open it with an internet connection.
